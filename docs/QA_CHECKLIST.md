# 바로영어 (`baro-english`) 실기기 QA 체크리스트 (iOS / Android)

Milestone 5 완료 기준 및 BugHunter QA 감사 항목(TC-01 ~ TC-12)을 기반으로 한 실기기 검증 체크리스트입니다.

## 1. 오디오 & TTS 실기기 검증
- [ ] **TC-01 (Android `ko-KR` 영어 TTS 확인):** 한국어 로케일 Android 실기기에서 오프라인 상태로 `1.0x`/`0.6x` 재생 시 한국어 억양 폴백 없이 영어(`en-US`)로 발화되는지 확인
- [ ] **TC-02 (연속 탭 레이스 방지):** 1초 내 5회 연속 다른 단어/속도 버튼 연타 시 마지막 1건만 단독 재생되고 종료 후 버튼이 정상 상태로 복귀하는지 확인
- [ ] **TC-03 (Android 콜드 스타트):** 앱 실행 직후 0.5초 내 A → B 단어 연타 시 A가 지연 재생되지 않고 B만 재생되는지 확인
- [ ] **TC-04 (`expo-audio` 에러 폴백):** 원격 MP3 로드 실패 또는 재생 중 비행기 모드 전환 시 `status.error` 감지 후 즉시 `expo-speech`로 폴백되고 UI 고착이 없는지 확인
- [ ] **TC-05 (iOS 무음/인터럽션):** iOS 무음 스위치 ON, 타 앱 음악 재생 중 덕킹, 전화 수신 종료 후 재재생이 모두 정상 동작하는지 확인
- [ ] **TC-06 (화면/백그라운드 이탈):** 재생 중 탭 전환, 기호 바텀시트 열기, 백그라운드 이동, 다른 단어 선택 시 기존 음성이 즉시 중단되는지 확인

## 2. 영구 저장 & 오프라인 캐시 검증
- [ ] **TC-07 (저장소 손상 복구):** AsyncStorage 손상 데이터 상태에서 재실행해도 크래시 없이 초기화·안내 배너가 정상 표시되는지 확인
- [ ] **TC-08 (오프라인 캐시 복원):** 온라인에서 단어 2~3개 검색 후 앱 완전 종료 → 비행기 모드 재실행 시 Tab 2에서 최근 찾아본 단어가 오류 없이 즉시 복원되는지 확인
- [ ] **TC-09 (API vs 캐시 레이스):** 미캐시 단어 검색(로딩 중) 직후 캐시된 단어 칩을 눌러도 로딩이 즉시 종료되고 이전 API 응답이 현재 단어를 덮어쓰지 않는지 확인
- [ ] **TC-12 (오프라인 영속성 E2E):** Tab 1 안내 배너 닫기, 기호 익힘 체크, Tab 2 한글 발음 힌트 Off 후 앱 재실행 시 깜빡임 없이 상태가 유지되는지 확인

## 3. 시니어 접근성 & 레이아웃 검증
- [ ] **TC-10 (큰 글씨 & 소형 기기):** iPhone SE(375pt) / Android 360dp + OS 글꼴 크기 1.5x~1.8x 설정에서 Tab 1 2열 그리드, Tab 2 오디오 버튼·헤더·리듬 블록, 바텀시트가 겹치거나 잘리지 않는지 확인
- [ ] **TC-11 (Android 15+ Edge-to-Edge SafeArea):** 3버튼 내비게이션 및 제스처 바 기기에서 하단 탭바와 `SymbolDetailSheet` 최하단 `익혔어요` 버튼이 시스템 바와 겹치지 않는지 확인
- [ ] **라이선스 출처 표기:** Tab 2 하단에 `Wiktionary (CC BY-SA 4.0) · CMUdict / Datamuse · MyMemory` 표기가 선명하게 표시되는지 확인
